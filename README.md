The High-Risk Loan Application Monitoring System allows authorized users to review and approve loans generated by clients.

---

## Examples

### Create Loan

Body: {
    id: 101 
    description: Loan for a house
    amount: 200,000
    createdAt: 2025-03-23
}
Authorization: Bearer [Token]
Responses: 
    201: Loan Created
    401: invalid Token
    403: Insufficient Role

### Retrieve Loans

Authorization: Bearer [Token]
Responses: 
    200: [
        {Loan1},
        {Loan2},
        {Loan3},
        ]
    401: invalid Token
    403: Insufficient Role

### Review Loan

Params: 
    id: 101
Authorization: Bearer [Token]
Responses: 
    200: {
        id: 101 
        description: Loan for a house
        amount: 200,000
        createdAt: 2025-03-23
    }
    401: invalid Token
    403: Insufficient Role

### Approve Loan

Params: 
    id: 101
Authorization: Bearer [Token]
Responses:
    200: {
        id: 101 
        description: Loan for a house
        amount: 200,000
        createdAt: 2025-03-23
    }
    401: invalid Token
    403: Insufficient Role
